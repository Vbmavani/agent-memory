# Learn agent memory the way I did

This is a record of how I learned **AI agent memory** in four days (3–7 November 2026), working with Claude. It keeps the order I went in, what I built, what I read and searched, how I thought it through, and the questions I actually asked. The code I built along the way is the chat app in this repo.

Read it in order if you're new. Each chapter says *why* a topic came up, not just what it is.

**Read it online:** [vbmavani.github.io/agent-memory/learn](https://vbmavani.github.io/agent-memory/learn/)
