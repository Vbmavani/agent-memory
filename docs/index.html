Agent memory, step by step

A language model remembers nothing between calls. Everything an agent seems to "remember" is either in its weights or put back into its prompt by the code around it. This site is how I learned to build that code: in four days, one memory type at a time, on a real chat app with a real database.

It keeps everything from the journey in one place: the map I started from, the explainers I asked for when I got stuck, what I read and searched, every question I asked, and the app's own docs. Start at the top and use Next at the bottom of each page.

Run it yourself

Needs Node.js 22+, a DeepSeek API key and a Postgres database. Clone agent-memory, then follow Run it locally in the README:

npm install
npm run embed:chats            # once: gives existing chats their embeddings
SEARCH_MODE=keyword npm run dev   # step 1: search by words only
npm run dev                       # step 2: words + meaning (default)

Keys and the database URL are read from the macOS Keychain or environment variables, never from files in the repo.
