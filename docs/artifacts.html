Every artifact from the journey

When I got stuck, I asked for a page: a map, an explainer, a simulator. These are all of them, in the order I made them, with what each one is for.

Three of these started as private Claude artifacts. The copies on this site are the same pages, with the shared nav bar added, so anyone can open them.

WhenPageWhat it isWhy I made itWhere
4 Nov Agent Memory Lab The six memory types (CoALA), the five operations every memory system does, 12 hands-on labs in three tracks, a reading list and a six-week plan. Lab checkboxes save in your browser. The first thing I asked for: "all types of memory, how it can be useful in AI agents… I want to try it out by myself and want to change the harness as well." On this site
5–6 Nov Vectors lab Words as 3 hand-written numbers (animal, food, big), drawn as arrows in 3-D. It ranks the closest words by cosine similarity, shows the math, and lets you make your own word with sliders. "Very, very basic… maybe just three numbers in an array… word to word." Inside the app: /vectors.html (code)
6 Nov Words Into Numbers How text becomes vectors, from zero, in seven steps with six diagrams: one number per word, a 2-D map, co-occurrence counts, live training, a sentence as a point, memory search, and a toy-vs-real table. "I'm still not able to understand this… from scratch: how it is trained… how it gets three numbers." On this site
6 Nov Vector visuals 2-D and 3-D training simulators. Each one starts from a random layout, moves one pass at a time, and shows what changed between steps. Also a step-by-step guide. "I want to have a simulator. I can click one by one, and then it should show me how those paths are working." 3-D · 2-D · Guide
7 Nov How Claude Remembers Anthropic's research post on the components of agent memory, in plain English: memory notes, the four-layer memory stack, benchmark results, and "dreaming" between sessions. "I don't know what this blog is about and what it is trying to solve, so make it easy to understand for me." On this site
7 Nov This site Everything above, connected with one nav bar, plus how I learned it, what I read and searched, my thinking process and every question I asked. So the whole journey is in one place, like the MCP guide in agent-toolkit. Overview
